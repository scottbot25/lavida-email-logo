# lavida-email-logo

Serves one file, `lavida-logo.png`, at the address every Lavida Heal email signature has loaded its logo
from since 2026-08-27 (the `notes` subdomain of lavidaheal.com). Every other path redirects to
https://lavidaheal.com/.

The wound tools that used to live at this address were retired on 2026-08-21. Their repo
(`lavidawound-composer`) is private and archived; this repo took the address over on 2026-10-02 so the
logo in every sent email keeps working.

- **Keep this repo public.** GitHub Pages on the Free plan needs a public repo.
- **Do not delete this repo, or rename or remove `lavida-logo.png`,** while any email signature, or any
  old email, points here. Removing it breaks the logo in all of them at once, silently.
- **If it is ever retired:** delete the `notes` DNS record at Namecheap the same day. A record left
  pointing at GitHub with no site behind it can be claimed by anyone on GitHub.

Nothing else belongs here: no tools, no data.
